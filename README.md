# Site do Colégio Holus

Novo site do Colégio Holus (São Manuel - SP), com todo o conteúdo do site original.

## Páginas
- `index.html` — Início
- `institucional.html` — Sobre Nós, Sistema FTD, EAD UNIP e Nossa Estrutura
- `cursos.html` — Educação Infantil, Ensino Fundamental e Ensino Médio
- `novidades.html` — todas as publicações (eventos, notícias e atividades)
- `contato.html` — Fale Conosco

## Como ver no computador
Abra o `index.html` no navegador.

## Notícias
As publicações ficam em `data/posts.js`, geradas a partir do WordPress antigo
(`data/raw_posts.json`) pelo script `data/build-posts.js`.
